# Direct Edit & Fast Turnaround Rules

## Strict Execution Directives
- **Direct Code Edits Only**: Apply changes directly to source code files without executing slow diagnostic commands.
- **NEVER Run Analyzers or Tests**: Do not run `flutter analyze`, `dart analyze`, or `flutter test` at any time.
- **Speed Optimization**: Avoid slow commands or background processes that increase waiting time.
- **Color Standards**: Maintain solid background colors for Edit (Gold `#D97706`), Delete (Dark Red `#991B1B`), and Details (Dark Green `#0F766E`).
